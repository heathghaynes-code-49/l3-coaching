# Blog workflow

The blog is generated by [Eleventy](https://www.11ty.dev/) from Markdown files — you (or Claude) write a short Markdown file per post, and the styled page (with the site's header/nav/footer) plus the sorted blog index are both built automatically.

`index.html` and `scorecard.html` are **not** part of this — they're still plain, hand-edited HTML files, untouched by any of this.

## Adding a new post

1. Create a new file: `eleventy/posts/your-post-slug.md` (lowercase, hyphens — this becomes the URL `/blog/your-post-slug.html`).
2. Fill in the front matter (the `---` block at the top) and write the body in Markdown below it:

```markdown
---
title: "Why Every Leader Needs a Discovery Interview"
date: 2024-03-04
displayDate: "March 4, 2024"
excerpt: "Most leadership problems trace back to one missing conversation. Here's how to have it."
heroImage: "/blog/images/discovery-interview-hero.jpg"
heroAlt: "Two people talking across a table"
photoCredit: "Photo by Jane Doe on Unsplash"
---

Opening paragraph of the post.

## A Major Section Header

Body copy with a **bolded key phrase** for emphasis.

{% pullQuote "An italic standout line — use sparingly, for the one sentence you want to hit hardest." %}

### A Numbered Sub-Point

- List item one
- List item two

{% toolImage "/blog/images/discovery-interview-tool.png", "Alt text describing the image", "Optional caption shown under the image" %}

> An indented pull quote, if the post has one worth calling out.
```

- `date` — ISO format, used to sort the blog index (newest first). Use the **original** publish date, not today's.
- `displayDate` — however you want the date to read on the page (e.g. `"March 4, 2024"`).
- `excerpt` — 1–2 sentences, shown on the blog index card and as the page's meta description.
- `heroImage` / `heroAlt` — the thematic photo, shown as the index thumbnail and as a banner under the post title. `photoCredit` is optional — omit it if there's nothing to credit.
- `photoCredit` — delete the line entirely if not needed (don't leave it blank).

Formatting reference for the body:
| Want | Write |
|---|---|
| Section header | `## Header text` |
| Sub-header | `### Sub-header text` |
| Bold | `**bold text**` |
| Bullet list | `- item` |
| Numbered list | `1. item` |
| Indented quote | `> quote text` |
| Italic standout line | `{% pullQuote "text" %}` |
| Tool/framework image with caption | `{% toolImage "/blog/images/x.png", "alt text", "caption" %}` (caption is optional — pass `""` to skip it) |

3. Put the post's images in `blog/images/`, named `<slug>-hero.jpg` and `<slug>-tool.png` (or whatever extension the file actually is).
4. That's it — no need to touch the blog index. It's generated automatically, sorted by `date`.

## Previewing locally

First time only:
```bash
npm install
```

Then, to preview with live-reload while writing:
```bash
npm start
```
Opens at `http://localhost:8080`.

To do a one-off production build (same thing Netlify runs):
```bash
npm run build
```
Output goes to `_site/` (gitignored — never edit files there directly, they get overwritten on the next build).

## Deploying

Same as before: push to a branch → Netlify builds it and gives you a Deploy Preview link → merge to `main` → live in 1–2 minutes. Netlify now runs `npx @11ty/eleventy` automatically as part of that (see `netlify.toml`) — no separate manual step.

## Editing the shared header/nav/footer

All blog pages (index + posts) share one layout file: [`eleventy/_includes/base.njk`](eleventy/_includes/base.njk). Edit it once and every blog page picks up the change on the next build — no more hunting through individual post files.

## The alternate row-list layout

[`blog-layout-option-b.html`](blog-layout-option-b.html) is a saved, static mockup of the alternate full-width-rows index layout (as opposed to the card grid currently live). It's not wired into the Eleventy build. If you ever want to switch to it, that's a matter of porting its row markup/CSS into `eleventy/blog.njk` and `eleventy/_includes/base.njk` — ask Claude to do it.
